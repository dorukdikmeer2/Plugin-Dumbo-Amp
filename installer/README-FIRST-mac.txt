DUMBDOCK AMP - MAC INSTALL (no coding)
1. Close Reaper.
2. Right-click (or Control-click) Install-DumbDockAmp.pkg, choose Open, then Open again.
   (Not Apple-notarised; the right-click is needed once.)
3. Follow the installer. It installs to /Library/Audio/Plug-Ins/VST3/DumbDock Amp.vst3
4. Reaper: Preferences > Plug-ins > VST > Re-scan. Add "VST3: DumbDock Amp" on a track.
Remove: delete that file from /Library/Audio/Plug-Ins/VST3.
