DUMBDOCK AMP - WINDOWS INSTALL (no coding)
1. Close Reaper.
2. Double-click  Install-DumbDockAmp.exe  and answer Yes.
   - If Windows says "Windows protected your PC": click "More info", then "Run anyway".
     (The file is not code-signed, which costs money; that is the only reason for the warning.)
   - Allow the administrator prompt. The installer copies ONE folder:
     C:\Program Files\Common Files\VST3\DumbDock Amp.vst3
3. Open Reaper: Options > Preferences > Plug-ins > VST > Re-scan.
4. On a track click FX, type "DumbDock", add "VST3: DumbDock Amp".
   A short welcome overview of the amps and options shows when the window opens.
Remove it any time with Uninstall-DumbDockAmp.exe.
Needs 64-bit Reaper on 64-bit Windows 10/11.
